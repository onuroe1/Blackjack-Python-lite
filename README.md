# 🃏 Blackjack CLI Game

My second Python project! Building on my first game, I moved towards more complex logic and game mechanics.

## 🚀 Key Features
- **Dynamic Ace Handling**: Automatically converts Ace value from 11 to 1 if the hand exceeds 21.
- **Dealer AI**: Implemented standard casino rules (Dealer hits until 17).
- **Infinite Loop**: Play as many rounds as you want without restarting the script.

## 🧠 What I learned
- Working with **Lists** and the `random` module for deck simulation.
- Creating **custom functions** with return values (`PunkteBerechnen`).
- Implementing complex **nested loops** (`while` inside `while`).

## 🕹️ How to Play
1. Run the script: `python blackjack.py`
2. Decide whether to "Hit" (j) or "Stand" (n).
3. Try to get closer to 21 than the dealer without busting!
